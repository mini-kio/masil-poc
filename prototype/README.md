# 마실

엘리스 AI 챌린지의 인터랙티브 PoC입니다. [마실의 하루](https://mini-kio.github.io/masil-poc/?rev=10) · [거실의 두 상황부터 보기](https://mini-kio.github.io/masil-poc/?rev=10#experience)

## 시연해 보기

1. 스크롤을 내려 집 전경, 거실의 안부와 충격음, 부엌의 주전자와 쌀 주문, 가족의 수령 확인과 저녁 통화를 순서대로 봅니다. 할머니가 허락하신 소식을 딸이 읽고 전화를 걸면, 할머니 쪽에서 전화벨이 울리고 두 사람이 통화를 나눕니다. 3D 할머니가 거실 소파에서 부엌과 식탁으로 이동합니다. 대화 상대에 따라 말풍선의 위치가 바뀌며, 소리를 끈 상태에서도 스크롤로 모든 대사를 읽을 수 있습니다.
2. 첫 화면에서 **소리와 함께 하루 따라가기**를 누르면 할머니가 먼저 아침 인사를 건네고 대화가 끝날 때마다 다음 장면으로 이동합니다. 휠·터치·이동 키로 다시 직접 넘길 수 있습니다. 중간에는 **하루 소리 켜기**로 현재 장면의 첫 대사부터 들을 수 있습니다. 휠과 터치로 움직이면 현재 스크롤 위치에 맞춰 카메라와 장면이 따라오고, 음성도 새로 도착한 장면에서 이어집니다.
3. **다른 답 골라보기**를 펼치면 여섯 상황에서 다른 답의 결과도 체험할 수 있습니다. 파형으로 재생 위치를 옮기고, 쿵 소리나 할머니 답변 구간부터 들어봅니다.
4. **설치와 개발**에서는 카메라가 식탁 위 3D 마실 패드로 다가갑니다. 패드를 가까이에서 읽고 더 내리면 같은 화면이 가족 휴대폰으로 이어집니다. 휴대폰에서 예시 결제 카드와 주문 한도, 할머니 댁 배송지, 말투·관심사·안부 시간·공유 범위를 차례로 설정하는 장면을 보고 개발 계획으로 넘어갑니다. 기술 계획은 펼쳐 볼 수 있습니다. **서비스 비교**는 실시간 오디오 이벤트를 다음 확인 질문과 가족의 행동으로 잇는 사례를 보여줍니다.

대사와 생활음은 준비된 시연 자료입니다. 주문, 일정 및 가족 알림의 결과는 브라우저에 모의 화면으로 표시합니다.

## 소스 실행

GitHub 저장소의 `prototype/`에 React 소스, Three.js 장면, 설치 설정과 시연 자산이 있습니다. Node.js 22.12 이상과 pnpm 11을 사용합니다.

```sh
cd prototype
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

`src/scenarios.js`에 대화와 버튼으로 이어지는 시연 흐름이 있고, `src/room.js`는 집 안 장면과 카메라를 구성합니다. 음원을 바꾸면 FFmpeg가 설치된 환경에서 `pnpm waveforms`를 실행해 파형과 길이를 갱신합니다. `dist/`는 GitHub Pages에서 열 수 있는 정적 결과물입니다.

할머니, 딸의 말풍선 속 3D 인물, 실내 소품은 Three.js로 모델링했습니다. 하루 이야기와 선택 시연의 대사 83종을 ElevenLabs의 고정 배역으로 녹음했습니다. 소식 도착음과 수신 벨소리는 ElevenLabs 효과음으로 만들었습니다. 할머니는 순자, 마실은 Eunhye, 딸은 suri입니다. 같은 배역의 여러 문장을 이어서 녹음한 뒤 나누고 음량을 맞췄습니다. 가족 설정 화면의 카드와 주소는 시연용 예시입니다.

실사용 연구에서는 음성·생활음 단서가 감지되면 앱이 어르신께 먼저 확인하고, 그 결과에 따라 가족 화면 상태를 갱신하는 흐름을 설계합니다. 연결 프로그램과 설치 안내, 시험 사례의 재사용·공개 조건은 후속 검토 항목입니다.
