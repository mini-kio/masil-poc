# 마실

엘리스 AI 챌린지의 인터랙티브 PoC입니다. [마실의 하루](https://mini-kio.github.io/masil-poc/?rev=6) · [거실의 두 상황부터 보기](https://mini-kio.github.io/masil-poc/?rev=6#experience)

## 시연해 보기

1. 스크롤을 내려 집 전경, 거실의 안부와 충격음, 부엌의 주전자와 쌀 주문, 가족의 수령 확인과 저녁 통화를 순서대로 봅니다. 3D 할머니가 거실 소파에서 부엌과 식탁으로 이동합니다. 대화 상대에 따라 말풍선의 위치가 바뀌며, 소리를 끈 상태에서도 스크롤로 모든 대사를 읽을 수 있습니다.
2. **하루 소리 켜기**를 한 번 누르면 현재 장면과 이후 장면의 음원이 이어집니다. 공간 표시와 장면 메뉴로 건너뛸 수도 있습니다.
3. **다른 답 골라보기**를 펼치면 여섯 상황에서 다른 답의 결과도 체험할 수 있습니다. 파형으로 재생 위치를 옮기고, 쿵 소리나 할머니 답변 구간부터 들어봅니다.
4. **설치와 개발**에서는 식탁 사진을 따라 태블릿, DIY 스피커, 가족 휴대폰의 연결 과정을 봅니다. 기술 계획은 펼쳐 볼 수 있습니다. **서비스 비교**는 실시간 오디오 이벤트를 다음 확인 질문과 가족의 행동으로 잇는 사례를 보여줍니다.

대사와 생활음은 준비된 시연 자료입니다. 주문, 일정 및 가족 알림의 결과는 브라우저에 모의 화면으로 표시합니다.

## 소스 실행

GitHub 저장소의 `prototype/`에 React 소스, Three.js 장면, 설치 설정과 시연 자산이 있습니다. Node.js 22.12 이상과 pnpm 11을 사용합니다.

```sh
cd prototype
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

`src/scenarios.js`에 대화와 버튼으로 이어지는 시연 흐름이 있고, `src/room.js`는 집 안 장면과 카메라를 구성합니다. 음원을 바꾸면 FFmpeg가 설치된 환경에서 `pnpm waveforms`를 실행해 파형과 길이를 갱신합니다. `dist/`는 GitHub Pages에서 열 수 있는 정적 결과물입니다.

설치 사진은 ImageGen으로 만든 예시 이미지이고, 3D 할머니와 실내 소품은 코드로 모델링했습니다. 대사 음원은 ElevenLabs에서 합성했습니다.

실사용 연구에서는 음성·생활음 단서가 도착하면 앱이 어르신께 확인하고, 확인 결과로 가족 화면 상태를 갱신하는 이벤트를 설계합니다. 연결 프로그램과 설치 안내, 시험 사례의 재사용·공개 조건은 후속 검토 항목입니다.
