# 마실

어르신과 가족을 이어주는 AI 말동무의 2026 엘리스 AI 챌린지 시연입니다.

`index.html`을 브라우저에서 열면 바로 시연할 수 있습니다. GitHub Pages는 `main` 브랜치의 루트에서 같은 파일을 제공합니다.

- **생필품 주문**: 쌀 4kg 한 봉지를 부탁하는 대화부터 시작합니다. 한 봉지는 18,900원, 두 봉지는 35,800원이며 시연용 자동 주문 한도는 배송비 포함 30,000원입니다. 자동 주문, 가족 승인, 수량 변경, 배송 전 취소와 수령 확인을 체험할 수 있습니다.
- **관심사 공유**: 어르신이 공유를 허락하신 관심사 소식만 가족 화면에 전달되는 흐름을 체험할 수 있습니다.
- **안부와 일정**: 가족이 남긴 안부 질문을 마실이 어르신께 여쭙고, 어르신이 확인하신 모임 일정을 공유 달력에 등록합니다.

이 시연의 주문과 결제는 가상으로 처리되며, 대사와 상호작용 상태는 각 브라우저 안에서만 동작합니다.

어르신과 마실의 대사 21개는 미리 합성한 MP3 파일로 재생합니다. 어르신 역에는 60대 한국어 여성 보이스를 사용했습니다. [ElevenLabs](https://elevenlabs.io/)
