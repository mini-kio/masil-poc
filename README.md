# 마실

어르신과 가족을 이어주는 AI 말동무의 2026 엘리스 AI 챌린지 시연입니다.

`index.html`을 브라우저에서 열면 시연할 수 있습니다. GitHub Pages는 `main` 브랜치의 루트에서 같은 파일을 제공합니다.

- **생필품 주문**은 쌀 4kg 한 봉지를 부탁하는 대화부터 시작합니다. 한 봉지는 18,900원, 두 봉지는 35,800원이며 시연 자동 주문 한도는 배송비 포함 30,000원입니다. 승인, 수량 변경, 배송 전 취소와 수령 확인을 체험할 수 있습니다.
- **관심사 공유**에서는 어르신이 한 번 허락한 가상 소식이 가족 화면에 나타납니다.
- **안부와 일정**에서는 가족이 남긴 질문을 어르신에게 묻고, 어르신이 확인한 모임 일정을 공유합니다.

이 시연의 주문과 결제는 모의 처리됩니다. 대사와 상호작용 상태는 시연을 여는 각 브라우저에만 있습니다.
