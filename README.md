# 마실

엘리스 AI 챌린지의 인터랙티브 PoC입니다. [웹 시연 보기](https://mini-kio.github.io/masil-poc/?rev=5#experience)

## 시연해 보기

1. **같은 말 비교**에서 두 음원을 들은 뒤 마실이 건네는 말을 확인합니다.
2. 큰 소리가 난 장면에서 뚜껑, TV, 통화 요청, 무응답을 골라 가족 화면을 비교합니다.
3. 주전자 타이머, 아침 안부, 음성 주문, 관심사 공유, 안부와 일정도 선택할 수 있습니다.
4. 설치와 개발에서 태블릿과 DIY 스피커의 설치 흐름, 이벤트 형식, 모델 평가 계획을 볼 수 있습니다.

대사와 생활음은 준비된 시연 자료입니다. 주문, 일정 및 가족 알림의 결과는 브라우저에 모의 화면으로 표시합니다.

## 소스 실행

GitHub 저장소의 `prototype/`에 React 소스, Three.js 장면, 설치 설정과 시연 자산이 있습니다. Node.js 22.12 이상과 pnpm 11을 사용합니다.

```sh
cd prototype
pnpm install --frozen-lockfile
pnpm dev
pnpm build
```

`src/scenarios.js`에 대화와 버튼으로 이어지는 시연 흐름이 있고, `src/room.js`는 집 안 장면과 카메라를 구성합니다. `dist/`는 GitHub Pages에서 열 수 있는 정적 결과물입니다.

실사용 연구에서는 음성·생활음 단서가 도착하면 앱이 어르신께 확인하고, 확인 결과로 가족 화면 상태를 갱신하는 이벤트를 설계합니다. 연결 프로그램과 설치 안내, 시험 사례의 재사용·공개 조건은 후속 검토 항목입니다.
